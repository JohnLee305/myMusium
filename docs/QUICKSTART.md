# 실행 및 재개 안내

## 데스크톱 미리보기

`C:\Dev\vr-museum\Builds\Windows\VRMuseum.exe`를 실행한다.

- WASD: 이동
- Q / E 또는 방향키 ← / →: 좌우 시점 회전 (누르고 있으면 계속 회전)
- 방향키 ↑ / ↓: 위 / 아래 보기 (최대 75도, 카메라가 뒤집히지 않음)
- 키보드만으로 이동·시점 조작 가능. 회전 속도는 초당 65도.
- 마우스 오른쪽 버튼을 누른 채 움직이기: 시점 회전
- 오른쪽 버튼을 놓거나 Esc: 마우스 해제
- Page Up / Page Down 또는 상단 Previous / Next: 전시실 이동
- 입구 좌우 이동 표지에 가까이 가도 방 전환. 로딩 후 입구 중앙에서 관람 재개.
- 창 닫기: 종료

현재 전시품은 **항아리·책·고리 조형물 3개**다. manifest.json의 순서대로 배치하며 각 artifact.json에서 이름·설명·크기를 읽는다.

실제 소장품이 없어도 샘플로 개발할 수 있다. 항아리는 직접 생성했으며 나중에 본인의 스캔 에셋으로 교체할 수 있다. JSON 수정 후 검증 도구를 실행하고 앱을 다시 열면 재빌드 없이 반영된다. 자세한 규칙은 `docs/ARCHIVE.md` 참고.

```powershell
C:\Dev\vr-museum\tools\validate-archive.ps1
```

모델이나 JSON이 잘못되면 대체 큐브와 오류 안내를 표시한다. 방당 최대30개를 자동 배치하며 초과분은 다음 방에서 볼 수 있다. 하나가 실패해도 다른 전시품은 정상 표시한다.

## Quest Link 테스트 (잔여 과제)

사용자가 테스트 가능한 시점에 진행한다.

1. Meta Link에서 Quest 3 연결을 확인한다.
2. Meta Link의 OpenXR runtime 상태를 확인한다. 최초 조사에서는 SteamVR로 설정되어 있었다.
3. Editor 메뉴에서 VR 모드를 실행하거나 아래 명령을 사용한다.

```powershell
C:\Dev\vr-museum\tools\open-viewer.ps1 -Vr
```

현재는 HMD와 좌우 컨트롤러의 위치/회전 입력을 설정했다. 실제 트래킹, 컨트롤러 동작 및 프레임 성능은 아직 검증하지 않았다. Grab/텔레포트는 후속 구현이다.
OpenXR 로더 시작에 실패하면 데스크톱 화면으로 돌아가며 안내 문구를 표시한다.

## 전시품 상세 설명 (PC)
- 전시품 또는 전시대를 왼쪽 클릭하면 상세 설명창이 열린다. 화면 중앙의 +를 전시품/전시대에 맞추고 F로도 선택할 수 있다(최대 12m, 벽/앞 전시대에 가린 대상은 선택되지 않음).
- 오른쪽 마우스를 누른 시점 조작 중에는 왼쪽 클릭 선택을 받지 않는다.
- 제목과 설명은 큰 한글 글씨로 표시되며, 긴 내용은 창 안에서 마우스 휠 또는 스크롤바로 읽는다. 기존 자료 제한(제목80자/설명400자)은 유지된다.
- 닫기 버튼 또는 Esc로 닫는다. 읽는 동안 WASD/QE/방향키/RMB 및 Page Up/Down·근접 방 이동을 멈춘다.
- 방 전환 함수가 호출되면 열린 설명과 선택 참조를 해제한다.
- 모델만 누락된 자료는 제목·설명과 모델 오류 안내를 표시한다. JSON 자체가 손상되면 대체 안내를 표시한다.
- 이번 패널은 데스크톱 화면용이다. Quest 컨트롤러 선택 및 HMD 안의 설명 패널은 후속 구현·실기기 검증 대상이다.
- 회귀 시험: tools/test-details.ps1 (별도 logs 시험자료, 실제 archive 변경 없음).

바탕화면의 **VR 박물관 (PC 관람)** 바로가기를 더블클릭하면 Unity Editor 없이 PC 관람 창이 열린다. 실제 museum-archive를 사용하며, 창의 X 또는 Alt+F4로 종료한다.


전시대에는 녹색·황동 명판이 표시된다. 제목·소개는 읽기 쉬운 길이로 줄여 보이며, 전시품·전시대·명판을 선택하면 원문 전체를 상세창에서 읽을 수 있다.


## 방별 색상 테마
관리페이지 상단 ‘전시실 색상·테마 조정’을 누르면 ‘방마다 다른 분위기’로 이동한다.
1. 꾸밀 전시실을 선택한다.
2. 기본 박물관/밝은 갤러리/밤의 전시실/따뜻한 서재 중 선택하거나 개별 색을 조정한다.
3. 네 벽·바닥·배경, 전시대, 명판, 방 안내판, 상세창, 조명 등 23개 색을 색상 선택기 또는 #RRGGBB 입력으로 변경할 수 있다.
4. ‘이 방의 테마 저장’을 누른다. 기본색 복원도 저장해야 반영된다.
5. 관람 앱을 종료하고 바탕화면 바로가기로 다시 실행한다. 방을 이동하면 각 방의 저장된 테마가 적용된다.
미리보기는 색 조합 참고용이며 실제 조명과 차이가 있다. 전시품 GLB의 재질 색은 원본을 유지한다. 테마를 저장하지 않은 기존 방은 기본색으로 표시된다.

## 관리 서버 켜기·끄기 (현재 실행 방식)
바탕화면 **VR 박물관 관리** 또는 Open-Curator.cmd를 열면 제어창이 나온다.
- **서버 켜기**: 서버가 꺼져 있을 때 시작한다.
- **관리페이지 열기**: 서버가 켜져 있을 때 기본 브라우저에서 페이지를 연다.
- **서버 끄기**: 저장 중인 요청이 없을 때 서버를 정상 종료한다. 저장 중이면 잠시 뒤 다시 누른다.
- 제어창이나 브라우저를 닫아도 서버는 유지된다. 종료하려면 서버 끄기를 누른다.
- 서버를 껐다 켠 뒤에는 기존 브라우저를 새로고침하거나 관리페이지 열기를 누른다.
- PC 관람 앱은 관리 서버 없이 사용할 수 있다.
이 절차는 과거의 ‘바로가기 실행 즉시 서버/브라우저 자동 열기’ 안내를 대체한다.

## PC 관람 중 회전·확대
1. 전시품 또는 전시대를 클릭하거나, 화면 중앙에 맞추고 F를 누릅니다.
2. 설명창 아래 **3D 크게 보기**를 누릅니다.
3. 왼쪽 모델 화면을 드래그하면 회전하고, 모델 위에서 휠을 움직이면 확대·축소합니다. 아래 회전/−/+ 버튼도 사용할 수 있습니다.
4. **초기화** 또는 **R**로 처음 시점으로 돌아갑니다. 오른쪽 설명은 별도로 스크롤할 수 있습니다.
5. **설명만 보기**로 돌아가거나 **닫기/Esc**로 관람을 계속합니다.
확대는 별도 화면에만 적용되므로 전시품의 실제 배치와 크기는 바뀌지 않습니다. 읽지 못한 모델은 확대 버튼이 비활성화됩니다. 이 설명창은 PC 마우스·키보드용입니다.

## Quest Link 전시품 잡기·확대 (실기기 확인 대기)
PC용 빌드에 VR 컨트롤러 상호작용을 구현했습니다. 자동검사는 모의 손 입력을 사용하며, 실제 Quest의 버튼·외곽선·진동·양안 화면·편안함은 아직 검증하지 않았습니다.

1. PC와 Quest Link를 연결한 후 **VR 박물관 (Quest Link)** 바로가기로 실행합니다. OpenXR를 사용할 수 없으면 PC 관람으로 전환됩니다.
2. 전시품에 컨트롤러를 향하면 하늘색 외곽선과 이름·잡기 안내가 표시됩니다. 명판과 전시대는 잡기 대상이 아닙니다.
3. **옆면 그립 버튼**을 누른 채 유지하면 전시품이 손 앞으로 이동합니다. 가까운 전시품은 손을 가져가 같은 버튼으로 잡습니다.
4. 손목을 돌려 전시품을 살펴봅니다. 다른 손을 관람용 전시품에 가까이 가져가거나 가리킨 뒤 그립을 누르면 양손 조작으로 바뀝니다. 양손 간격으로 확대·축소하고 두 손의 방향으로 회전합니다.
5. 처음 손에 들었을 때 가장 긴 변은 28cm입니다. 양손 조절은 그 크기의 0.25~3배로 제한합니다. 한 손의 그립을 놓으면 남은 손으로 계속 잡습니다.
6. **A 또는 X**는 관람용 크기·회전을 초기화합니다. **B 또는 Y**, 또는 마지막 손의 그립을 놓으면 전시대로 돌아갑니다.

손에 든 것은 렌더링 복사본입니다. 원래 전시품은 잠시 숨겨지고 자리에 하늘색 표시가 남습니다. 놓으면 약 0.25초 후 돌아가기 시작해 원래 표시로 복구됩니다. 원본 파일과 배치·크기는 저장 변경되지 않습니다. 방 전환·잡은 컨트롤러 추적 손실·앱 포커스 손실 시 즉시 정리합니다. 들고 있는 동안 출입구 자동 방 이동은 잠시 차단됩니다.

현재는 컨트롤러용입니다. 맨손 추적, 던지기, VR 전체 설명창, 텔레포트 이동은 후속 작업입니다. 관리 서버를 켜지 않아도 관람할 수 있습니다.

실기기 확인 목록: [Quest Link 테스트 체크리스트](QUEST-TEST-CHECKLIST.md). 테스트는 나중에 진행하며 현재 전 항목 미확인입니다.

## 타이쿤 실험 · 관람객

바탕화면 **VR 박물관 (타이쿤 실험)**으로 실행합니다. 기존 PC/Quest/관리 바로가기와 데이터 폴더는 별도입니다. 관람객1명이 입장해 최대3개 정상 전시품을 구경하고 퇴장하며, 목표 인원보다 적으면 새 손님이 들어옵니다.

오른쪽 **관람객 · 타이쿤 실험**의 −/+로 목표 인원0~6명을 조절하고 **모두 끄기/켜기**로 표시를 바꿉니다. 설정은 현재 실행 중에만 유지됩니다. 관람·퇴장 숫자는 현재 세션 누적 값이며 만족도나 수입은 아닙니다. 관리페이지 인원 설정·저장은 아직 없습니다. 방을 바꾸면 이전 방의 관람객을 정리하고 새 방에서 입장합니다.

기존처럼 WASD와 마우스로 전시실을 둘러보실 수 있습니다. 외형을 나중에 추가하는 방법은 [캐릭터 확장 문서](VISITOR-EXTENSION.md)를 참고합니다. 현재 실제 캐릭터는 일상복1종이며 다양한 옷차림/여성 등은 이후 추가할 수 있습니다. 실제 Quest에서의 NPC 거리감·성능은 별도 확인 대상입니다.

관람객 패널이 안 보일 때: 웹 관리페이지나 기존 버전 보관/Quest Link 버전이 아니라 **VR 박물관 (타이쿤 실험)**을 실행했는지 확인합니다. 패널은 PC 관람 창 오른쪽 위에 표시됩니다. 설명/확대창이 열려 있으면 Esc 또는 닫기로 관람 화면으로 돌아오세요. 현재 헤드셋 내부와 웹 관리페이지에는 이 인원 패널이 없습니다.

바로가기 정리: **PC 관람**과 **타이쿤 실험**은 같은 최신 실험 앱입니다. 기존 관람 앱은 **기존 버전 보관**으로 실행합니다. tools/setup-viewer-shortcuts.ps1로 재설정할 수 있습니다.
