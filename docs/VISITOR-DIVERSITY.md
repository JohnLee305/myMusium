# 관람객 100가지 조합 외형

2026-10-15 · 타이쿤 실험 전용 · PC 실행 검증, Quest 미확인

## 제공하는 외형

남성50가지·여성50가지 조합 외형을 추가했습니다. 기존 일상복1종을 포함해 카탈로그에는 **101가지**가 있습니다. 100개의 별도 제작 인물 모델을 구매한 것이 아니라, 공식 모듈식 모델의 서로 다른 머리·상의·하의·신발을 조합한 외형입니다. 피부5색·머리5색·상의8색·하의6색·신발4색의 공유 머티리얼을 적용해 시각적 차이를 더했습니다. 조합마다 키도 소폭 다릅니다.

남녀 팩은 서로 자신의79본 리그와 Walk/Idle_Neutral 클립을 사용합니다. 모듈 조합은 같은 팩 안에서만 하므로 남녀의 다른 부위를 억지로 연결하지 않습니다. 무기·우주복·군장·왕관 등은 이번 관람객 조합에서 제외했습니다.

`Assets/Museum/Visitors/Diversity/recipes.json`은 외형별 원본/4부위/팔레트를 기록합니다. 생성 시 실제 vertex·삼각형·원본 재질색의 해시로 같은 부위 조합을 중복 집계하지 않습니다. 고정된 생성 시드를 사용하여 다시 실행해도 ID와 부위 조합이 바뀌지 않습니다.

## 입장 시 선택

- 기존 인원0~6명 설정 안에서 손님이 입장할 때 외형을 무작위 선택합니다. **100명 동시 생성 기능이 아닙니다.**
- 설정이 없는 새 외형은 기본 사용·비중1로 참여합니다. 기존 저장 인원·속도와 이미 지정한 외형별 설정을 바꾸지 않습니다.
- 현재 방에 없는 외형을 먼저 선택하고, 남은 외형 중 저장 비중에 따라 추첨합니다. 사용 가능한 외형이 적으면 같은 외형의 동시 등장도 허용합니다. 무한 재추첨하지 않습니다.
- 관리페이지에서 ‘등장 가능’ 개수, 이름/남성/여성 검색,12개씩 페이지 이동, 모두 사용/끄기, 외형별 비중을 제공합니다. 검색·페이지를 옮겨도 수정값을 유지하며 저장은 전체 외형에 적용됩니다.
- 현재101종 모두 비중1이라면 다양한 외형이 섞여 나오도록 기본 준비되어 있습니다. 이미 켜 놓은 앱에는 새 빌드가 적용되지 않으므로 앱을 닫았다가 PC 관람 바로가기로 다시 실행합니다.

## 추가 생성·재빌드

Unity 메뉴 **Museum → Visitors → Generate 100 modular appearances**는 이번100조합을 생성/등록합니다. 기존 생성 프로필의 인원과 관계없는 키·속도·비중 등 조절값을 유지하면서 정식 애니메이션 참조와 생성 팔레트를 맞춥니다. 일반 BuildDesktop은 이 생성기를 매번 실행하지 않고 현재 카탈로그를 그대로 빌드합니다.

새 제작자/모델은 기존 [프로필 확장 절차](VISITOR-EXTENSION.md)를 따릅니다. 이번 생성기가 사용자가 추가한 외형을 삭제하지 않습니다. 생성했던 ID를 카탈로그에서 뺀 뒤 생성기를 명시적으로 다시 실행하면 이번100항목이 재등록됩니다.

Editor 전용 `__preview` 클립은 Player에 포함되지 않으므로 정식 import 클립만 연결합니다. 모델 중심과 바닥은 애니메이션 초기 포즈의 실제 skinned vertex 범위로 정렬합니다. 단순 import bounds와 다른 리그의 오프셋을 그대로 이동 기준점으로 쓰지 않습니다.

## 출처와 조건

- [Quaternius Ultimate Modular Men](https://quaternius.com/packs/ultimatemodularcharacters.html): 공식 배포 폴더의 Humans_Master.fbx.
- [Quaternius Ultimate Modular Women](https://quaternius.com/packs/ultimatemodularwomen.html): 공식 배포 폴더의 All together.fbx.
- 이번 두 배포 폴더에서 별도로 받은 License.txt는 모두 CC0 1.0을 명시합니다. 여성 폴더 License.txt의 제목에도 Males라는 원문 표기가 있으므로 원문을 수정하지 않고 출처와 함께 보관합니다. 다른 신규 팩에 이 판단을 적용하지 않습니다.
- `third_party/visitors/quaternius-modular-diversity/`에 수령 원본·각 라이선스·조합 안내·파일SHA-256과 공식 파일ID를 보관합니다. 해시는 수령 파일 식별용이며 제작자 공개 체크섬과 비교했다는 의미가 아닙니다.

## 검증 도구와 한계

`tools/test-visitor-diversity.ps1`: 새100외형 각각의 실제4개 skin 변형·크기·발높이·중심·재질,101외형의12,000회 추첨, 동시6종 중복 방지를 검사하고 비교용100외형 화면을 저장합니다. 이 비교 화면에서만100개를 동시에 배치하며 정상 관람은0~6명입니다.

`tools/test-visitor-diversity-admin.mjs`: 실제101목록/남50·여50/활성/전체101설정 저장 검사를 별도 자료에서 수행합니다. 기존 관람객과 설정 유지 시험도 별도로 실행합니다. 실제 Quest 프레임 성능·양안 표시·거리감은 후속입니다.

![100가지 실제 외형 비교](assets/visitor-diversity.png)

포즈 치수 계산은 [Unity 6.3 BakeMesh 문서](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/SkinnedMeshRenderer.BakeMesh.html)의 배율 보상 옵션을 사용하여 TransformPoint와의 중복 배율을 피합니다. 실행 초기1회만 실제 vertex 범위를 계산하며, 매 프레임 전체 메시를 굽지 않습니다.
