# GPT-6 개발 모델 전환

기록일: 2026-10-04 (Asia/Seoul)

## 확인한 사실
- Codex 사용자 config.toml의 기본 모델은 gpt-6.1-sol, model_reasoning_effort는 low다. 이 작업에서 설정을 변경하지 않았다.
- 현재 실행 대화의 모델 선택은 설정 파일만으로 입증할 수 없다. 앱의 모델 선택에 GPT-6.1 Sol이 표시되는지 확인한다.
- apps, tools, docs 검색에서 OpenAI API 호출 및 GPT 모델 지정이 발견되지 않았다. 현재 전환은 개발 도구의 모델을 대상으로 한다.
- 개발 루트 C:\Dev\vr-museum, PC Quest Link 우선, standalone 후속 원칙을 유지한다.
- 기존 완료점은 방당 30개 전시, 방 확장/전환 및 자원 해제, HTML 등록/방 관리, 벽부형 간판이다.
- 과거 검증은 STATUS/WORKLOG에 기록된 결과다. 이번 작업에서 빌드나 기능 테스트를 재실행한 것은 아니다.

## 적용 방침
- 기본 개발 모델: GPT-6.1 Sol (gpt-6.1-sol).
- 기존 추론 low를 최초 비교 기준으로 유지한다. 복잡한 문제가 반복되면 medium/high를 비교한다.
- Astra는 어려운 설계/디버깅의 비교 후보이며 자동 라우팅은 구현하지 않는다.
- 실제 archive는 보존하고 시험 자료는 별도 fixture에서 사용한다.
- 완료 설치나 라이선스 작업을 반복하지 않는다. 각 작업 시작/종료 시 STATUS와 WORKLOG를 기록한다.

## 다음 평가 작업 (예정)
1. 별도 개발 작업으로 전시품 상세 설명 패널을 구현한다.
2. 변경 전 Git 상태와 기존 코드 경로를 확인하고 기존 변경을 보존한다.
3. 소요 시간, 수정 횟수, 가능한 범위의 사용량 및 기능 완성도를 기록한다.
