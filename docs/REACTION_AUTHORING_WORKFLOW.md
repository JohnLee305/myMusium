# 모델 맞춤 대사 제작 운영

공유 원본은 [museum-model-reactions 스킬](../.agents/skills/museum-model-reactions/SKILL.md)이다. 처리 주체는 이 스킬을 실행하는 Codex/Work 에이전트이며, 스킬은 제작 방법과 완료 기준을 정의한다. 업로드 시 자동 실행되는 별도 서비스는 이번에 만들지 않았다.

## 실행 요청

- `새로 올린 모델의 맞춤 대사를 작성하고 적용해 줘.`
- `$museum-model-reactions 총 모델의 대사 40개 이상을 작성·검토하고 관람객에게 적용해 줘.`
- `대사가 미완성인 전시품들을 찾아 후보만 만들어 줘.`

저장소의 AGENTS.md가 관련 요청을 스킬로 연결한다. 저장소 원본은 `.agents/skills/museum-model-reactions/`에 둔다. 이 PC의 사용자 스킬 폴더에도 같은 사본을 설치하며, 갱신 시 원본과 설치본 SHA-256을 대조한다. 실행 중인 대화의 스킬 목록이 즉시 새로고침됐다고 가정하지 않는다. 목록에 없으면 AGENTS에 연결된 SKILL.md를 직접 읽어 수행한다. 다른 환경은 저장소 사본으로 동일한 절차를 수행할 수 있다.

## 동작 순서

1. 최신 Git/작업 상태 확인 → 요청 범위·실제 개인 Archive 확인.
2. 모델 여러 각도 관찰 → 모델/설명 지문과 관찰 근거를 로컬 메모에 기록.
3. 성향별10개 이상, 기본40개 맞춤 초안 작성 → 기존 승인문 보존.
4. 사실·관찰·질문 구분, 의미 중복·문장 길이·스키마 검사.
5. 요청이 후보 작성이면 draft 저장. 적용 요청이면 검토한 대상 문구를 approved로 저장.
6. API/관리 화면의 개수·성향·enabled/stale 확인 → 바탕화면 앱/Archive 연결 확인 → 가능하면 실제 감상 말풍선 확인.
7. 검증 수준·남은 항목 기록. 공유 지침/코드는 GitHub에 통합하되 개인 대사·모델·메모는 공개하지 않음.

| 기록 상태 | 의미 |
|---|---|
| 관찰 완료 | 모델을 직접 보고 근거와 지문 기록 |
| 초안 작성 | 맞춤 후보 저장, 아직 관람객 표시 대상 아님 |
| 검토 완료 | 근거·의미 중복·계약 검사 완료 |
| 승인·활성화 확인 | 승인 저장 및 enabled/stale/API 확인 |
| 실제 표시 확인 | 관람객 말풍선과 저장 문구 직접 대조 |

이 표는 에이전트 작업 기록 기준이다. 관리 화면에 새 작업 큐/상태 UI가 구현됐다는 뜻은 아니다. 파일/프로세스 확인만으로 마지막 상태를 기록하지 않는다.

현재 계약은 최대96개/64KiB/문구72 UTF-16 코드 유닛이다. 모델 교체 지문은 에이전트가 직접 비교하며 모델만 바뀔 때의 자동 stale 처리는 미구현이다. 모델당1,000개 확장 및 자동 처리 서비스는 [후속 계획](REACTION_CONTENT_SCALE.md)으로 관리한다.
