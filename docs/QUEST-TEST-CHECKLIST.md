# VR 박물관 · Quest Link 테스트 체크리스트

작성: 2026-10-15 · 대상: PC 연결 Quest Link 관람

**현재 상태: 구현과 PC 모의검사 완료, 아래 실기기 항목은 모두 미확인입니다.**
지금 테스트하실 필요는 없습니다. 나중에 위에서부터 진행하시고, 정상인 항목에 체크해 주세요. 문제가 있거나 아직 할 수 없는 항목은 체크하지 않고 맨 아래에 기록하시면 됩니다.

테스트 날짜: __________  /  기기: __________  /  연결 방식(케이블·무선): __________

## 1. 처음 실행하기

- [ ] **01 연결·실행** — Quest Link 연결 후 바탕화면 **VR 박물관 (Quest Link)**를 실행합니다. 헤드셋 안에서 박물관이 보여야 합니다. PC 화면만 열리면 연결 확인이 필요합니다. 관리 서버는 켜지 않아도 됩니다.
- [ ] **02 시점 추적** — 고개를 좌우·위아래로 움직입니다. 시야가 자연스럽게 따라오고 바닥 높이와 전시대 크기가 어색하지 않아야 합니다.
- [ ] **03 양쪽 눈 화면** — 같은 전시품을 한쪽 눈씩 번갈아 확인합니다. 어느 한쪽에만 모델이나 외곽선이 보이거나, 색·위치가 이상하게 달라지지 않아야 합니다.
- [ ] **04 양쪽 컨트롤러** — 왼손과 오른손을 따로 움직입니다. 표시와 포인터가 각각 해당 손을 따라와야 합니다.

## 2. 가리키고 잡기

아래 항목은 **왼손·오른손 모두** 확인해 주세요. 옆면 그립은 손으로 쥐듯 누르는 버튼입니다.

- [ ] **05 포커스** — 전시품을 가리키면 하늘색 외곽선·이름·잡기 안내가 보이고, 다른 곳을 가리키면 강조가 사라져야 합니다. 외곽선이 모델 전체를 가리지 않는지도 확인합니다.
- [ ] **06 진동** — 새 전시품에 포커스가 맞으면 짧은 진동이 오는지 확인합니다. 계속 가리키는 동안 진동이 반복되지 않아야 합니다.
- [ ] **07 선택 구분** — 명판·전시대·벽은 잡히지 않아야 합니다. 다른 물체에 완전히 가려진 전시품도 포인터로 잡히지 않아야 합니다.
- [ ] **08 원격 잡기** — 몇 걸음 떨어진 전시품을 가리키고 그립을 누른 채 유지합니다. 손 앞으로 부드럽게 이동하고, 지나치게 얼굴 가까이 오지 않아야 합니다. 현재 최대 선택 거리는 10m입니다.
- [ ] **09 근접 잡기** — 닿을 수 있는 전시품에 손을 가까이 대고 그립을 누릅니다. 포인터를 정확히 맞추지 않아도 손 근처의 전시품이 잡혀야 합니다. 현재 근접 판정 거리는 약 14cm입니다.
- [ ] **10 원래 자리 표시** — 잡고 있는 동안 전시대의 원본은 숨겨지고, 원래 자리에 하늘색 표시가 남아야 합니다. 원본과 복사본이 겹쳐 보이지 않아야 합니다.

## 3. 손에 들고 살펴보기

- [ ] **11 한 손 회전** — 손목을 돌려 앞·뒤·옆·아래를 봅니다. 전시품이 손을 따라 움직이고 떨림이나 갑작스러운 방향 전환이 없어야 합니다.
- [ ] **12 양손 확대·축소** — 다른 손을 들고 있는 전시품에 가까이 가져가거나 가리킨 뒤 그립을 누릅니다. 두 손을 벌리면 커지고 모으면 작아져야 합니다. 처음 크기는 가장 긴 변 28cm이며, 조절 범위는 그 크기의 0.25~3배입니다.
- [ ] **13 양손 회전** — 양손으로 잡은 상태에서 두 손을 잇는 방향을 바꿉니다. 전시품 방향이 자연스럽게 바뀌고, 손이 가까워졌을 때 심하게 튀지 않아야 합니다.
- [ ] **14 손 바꾸기** — 양손으로 잡다가 처음 잡은 손의 그립을 놓습니다. 남은 손에서 계속 잡히고 위치가 갑자기 튀지 않아야 합니다. 반대 방향도 확인합니다.
- [ ] **15 초기화** — 오른손 A 또는 왼손 X를 누릅니다. 관람용 크기와 회전이 초기 상태로 돌아가야 합니다. 한 손·양손 상태에서 각각 확인합니다.
- [ ] **16 안내 가독성** — 손 아래 안내가 읽히고 전시품을 과하게 가리지 않아야 합니다. 명판·방 이름·포인터도 밝은 배경과 어두운 배경에서 확인합니다.

## 4. 돌려놓기와 복구

- [ ] **17 그립 놓기** — 마지막으로 잡은 손의 그립을 놓습니다. 약 0.25초 후 복귀가 시작되어 원래 전시 위치·크기로 돌아가야 합니다. 두 손 중 한 손만 놓았을 때는 돌아가지 않아야 합니다.
- [ ] **18 버튼으로 복귀** — 잡은 상태에서 오른손 B 또는 왼손 Y를 누릅니다. 원래 자리로 돌아가고 다시 잡을 수 있어야 합니다.
- [ ] **19 반복 조작** — 잡기 → 확대 → 복귀를 10회 정도 반복합니다. 복사본·외곽선이 남거나 전시품이 사라지지 않고, 점점 느려지지 않아야 합니다.
- [ ] **20 컨트롤러 추적 손실** — 잡은 컨트롤러를 잠시 내려놓는 등 실제로 추적이 끊기는 상황에서 확인합니다. 추적 손실이 감지되면 전시품은 원래 자리로 복구되어야 합니다. 다시 추적되면 새로 잡을 수 있어야 합니다. 추적 손실을 재현하지 못하면 ‘미확인’으로 둡니다.
- [ ] **21 앱 전환·복귀** — 잡은 상태에서 시스템 메뉴를 열거나 PC에서 다른 앱으로 전환한 뒤 돌아옵니다. 앱 포커스나 일시정지 상태가 바뀌었다면 전시품이 복구되고 조작이 다시 가능해야 합니다. 메뉴가 앱 포커스를 유지하는 경우는 별도로 기록합니다.
- [ ] **22 방 전환 정리 — 가능할 때** — 출입구에 접근할 수 있는 경우 확인합니다. 전시품을 들고 있을 때는 자동 방 전환이 차단되고, 돌려놓은 뒤 방을 바꾸면 이전 방의 복사본·외곽선이 남지 않아야 합니다. 현재 텔레포트 이동은 미구현이므로 출입구에 접근하기 어렵다면 보류합니다.
- [ ] **23 재실행·원본 유지** — 관람 앱을 종료하고 다시 실행합니다. 전시품 위치·크기·설명이 이전과 같아야 합니다. 관람 중 확대가 관리페이지의 저장된 배율을 바꾸지 않아야 합니다.

## 5. 모델별 표시와 사용감

- [ ] **24 가져온 모델** — 샘플 책 외에 인터넷에서 받은 등록 모델도 잡아 봅니다. 텍스처·색·앞뒷면이 정상이고 작은 모델도 손에서 충분히 볼 수 있어야 합니다. 실제로 확인한 모델 이름을 기록합니다.
- [ ] **25 실패한 모델 — 시험자료가 있을 때** — 읽지 못한 모델은 잡히지 않고, 같은 방의 정상 전시품은 계속 사용할 수 있어야 합니다. 이 확인을 위해 실제 전시 파일을 지우지는 않습니다.
- [ ] **26 움직임·편안함** — 고개 움직이기·잡기·확대·복귀를 잠시 반복합니다. 눈에 띄는 끊김·화면 떨림·지연이나 불편함이 있는지 기록합니다. 불편하면 그 시점에서 중단하고 어떤 동작이었는지 알려주세요.
