# 제품 기본안 — 무엇을 만들 것인가

## 경험을 판단할 기준

목록에서 물건을 고르고 실제 공간에 놓는 일이 짧고 예측 가능해야 한다. 작은 수정마다 확인창이 뜨지 않아야 하며, 실수는 쉽게 취소할 수 있어야 한다. 카탈로그는 발견하는 재미를, 보관함은 내가 가진 물건을 관리하는 편리함을 맡는다.

화려한 경제 수치보다 물건의 생김새·크기·색·배치 결과를 먼저 보여준다. 개발용 ID·좌표·revision은 일반 화면에 노출하지 않는다. 크기는 사용자가 판단할 수 있게 cm/m로 보여준다.

## 첫 시험판의 구성

20×16m 신규 가상 방을 쓴다. 이는 시험용 크기이며 기존 방 16.4×19m를 변경하지 않는다. 전시대(0.8×1.0×0.8m), 꽃병(0.12×0.18×0.12m), 큰 장애물(2.0×1.0×0.8m)을 우선 사용한다. 순서는 가로 X / 높이 Y / 깊이 Z다.

가상 기본 모델과 색상 세 개로 조작을 검증한다. 전시대의 상판 높이는 1m, 사용 가능 면은 0.7×0.7m다. 원점은 밑면 중심이고 앞은 +Z다. 색상 칩은 아이보리·짙은 녹색·짙은 회색을 사용한다. 최종 미술 에셋의 외관은 이 시험 모델과 별도다.

첫 체험에서 확인할 것: 10초 안에 목록에서 전시대를 찾아 놓는가, 꽃병이 상판에 자연스럽게 붙는가, 잘못 놓아도 취소·되돌리기가 이해되는가, 보관한 물건을 다시 찾는가. 목표 시간은 검토 기준이며 검증 완료 수치가 아니다.

## 카탈로그와 보관함의 기본 규칙

카탈로그는 종류당 한 카드, 색상은 카드 안에서 선택한다. 보관함은 같은 정의·버전·색상·개체 설정의 루트끼리 수량으로 묶는다. 자식이 붙은 물건은 ‘소품 포함’으로 표시하며 단순 물건과 합치지 않는다. 저장은 개별 instanceId를 유지한다.

보관함에서 다시 놓을 때 기존 ID를 사용하고 새 소유 물건을 만들지 않는다. 같은 유형이 여러 개면 마지막 회수 순, ID 순으로 안정적으로 선택한다. 상세 목록에서 특정 개체를 선택할 수 있다.

고유 소장품은 일반 장식과 다른 목록이다. ‘미전시/전시 중/보관된 전시대에 연결’ 상태를 표시한다. 실제 고유 전시 연결은 후속 계약 Gate 이후 구현한다.

## 처음 넣지 않는 범위

다층·계단·연속 건물, 임의 물건 쌓기, 상판 위에 또 선반 쌓기, 경제·판매, 완성 방 공유, 실시간 멀티 편집, 자유 회전의 출시 보장은 첫 시험판 범위 밖이다. 해당 기능을 구현 담당자가 임의로 덧붙이지 않는다.
