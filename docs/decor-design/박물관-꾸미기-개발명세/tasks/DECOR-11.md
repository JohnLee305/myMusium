# DECOR-11 · 실제 박물관 통합·이전 Gate

상태: 미착수. 이 카드는 작업 선점이나 실행 승인을 대신하지 않는다. 실제 저장소 AGENTS 및 담당 Gate를 먼저 따른다.

## 선행과 읽기

- 선행: 08~10의 하위 구현·검토 완료
- 읽기: 최신 소스 AGENTS/LIVE_STATUS/PROJECT_STATE, 확정된 통합 ADR와 하위 인계
- 공통 규칙: ../05-인계와검토.md. 관련 카드·계약·선행 인계만 우선 읽고 과거 전체 로그를 다시 읽지 않는다.

## 수정 예정 영역

- `docs/handoffs/DECOR-11.json`
- `tools/확정된-이전-및-회귀-도구`
- `실제 변경 경로는 08 하위 카드에서 지정`

새 파일 이름은 기준안이다. 충돌하는 기존 파일이 있으면 내용을 보존하고 인계에 알린다. 공유 DTO를 임의로 변경하지 않는다.

## 구현 또는 설계할 내용

1. 가상 legacy 전체 이전·복구를 먼저 시험하고 실제 자료 이전 계획과 보호 목록을 작성한다.
2. 기존 관람·상세·VR 복사본·테마·동선·큐·자동 관람객 회귀를 실행한다.
3. 사용자 확인 가능한 결과를 제시한 뒤 저장소 규칙에 따라 통합/실행판 반영한다.
4. 배포 후 개인 자료·실행 경로·바로가기·신구 저장 정본을 확인한다.

## 합격 기준

- 기존 배치 좌표/소장품/설명/반응/설정 보존 증거.
- 미리보기→저장→앱 재실행→실제 관람 확인.
- 실제 PC 마우스·Quest Link 착용 컨트롤러로 편집/저장/관람 확인. 미검증이면 양쪽 통합 완료 보류.
- 원격 통합 여부·실행판 반영 여부를 각각 기록.

검사 도구 이름은 예정이며 현재 존재/통과를 주장하지 않는다. 구현 담당자가 실행 가능한 검사와 재현 절차를 함께 제공한다. 순수 로직 검사는 Unity 전체 빌드 없이 실행 가능하게 하고, UI/실행 검사는 실제 Player에서 확인한다.

## 제외 범위

이 Gate 카드에 파일 범위가 없다는 이유로 무제한 구현 금지. 08에서 확정한 하위 카드가 선행.

## 인계와 다음 행동

저장소 규약의 docs/handoffs/DECOR-11.json에 변경 파일·실제 검사·실패·미검증·계약 변경 여부를 기록한다. DECOR-12 체감 검토.

## PC·VR 동등 지원 개정

[공통 조작 계약](../06-PC-VR-공통조작.md)과 DECOR-17 검증 인계를 읽는다.08의 선행은07 및17 검토 완료다. 이후 카드는 그 계약을 이어받는다. 모든 신규 도구는 PC 화면과 VR 공간 메뉴에서 같은 명령·저장·오류처리 경로를 사용한다.08은 관람용/편집용 입력 소유권과 양쪽 모드의 진입·퇴장·실패복구 책임표를 포함한다.09/10은 소장품/조명/마감의 양쪽 UI·컨트롤러 경로를 하위 카드에 넣는다.11/12는 실제 PC 편집→VR 재실행/수정→PC 재확인과 양쪽 사용자검토를 수행한다. Quest 미검증을 남긴 채 PC·VR 통합 완료라고 기록하지 않는다.
