# DECOR-04 · 직각 배치와 표면·충돌 검사

상태: 미착수. 이 카드는 작업 선점이나 실행 승인을 대신하지 않는다. 실제 저장소 AGENTS 및 담당 Gate를 먼저 따른다.

## 선행과 읽기

- 선행: DECOR-01 검토 완료
- 읽기: 03-공통계약 2~3절, 01의 시험 모델 크기
- 공통 규칙: ../05-인계와검토.md. 관련 카드·계약·선행 인계만 우선 읽고 과거 전체 로그를 다시 읽지 않는다.

## 수정 예정 영역

- `apps/quest-viewer/Assets/Museum/Runtime/Decor/Domain/DecorGeometry.cs`
- `apps/quest-viewer/Assets/Museum/Runtime/Decor/Domain/DecorPlacementValidator.cs`
- `tools/test-decor-placement.ps1`

새 파일 이름은 기준안이다. 충돌하는 기존 파일이 있으면 내용을 보존하고 인계에 알린다. 공유 DTO를 임의로 변경하지 않는다.

## 구현 또는 설계할 내용

1. 0/90/180/270 yaw의 부모-자식 좌표 변환과 회전 box를 구현한다.
2. 1mm 정규화, 25cm/5cm snap, 양/음 반칸 반올림을 명세대로 구현한다.
3. 바닥 높이·상판 지지·자식끼리 충돌·방 안 포함·예약 영역을 검사한다.
4. stored 루트의 방 충돌은 생략하되 자손 지지/겹침은 검사한다.
5. 형식·참조 검사와 연결하여 첫 세로 기능의 전체 ValidationReport를 제공한다.

## 합격 기준

- fixtures/cases.json의 모든 의미 오류 코드를 검출하고 정상 2종 통과.
- yaw90 부모를 옮기면 자식 world 좌표가 수학적 기대값과 일치.
- ±0.125의 snap 결과가 ±0.25; 저장 재읽기에서 재정렬 없음.
- 전시대 상판 경계 접촉은 허용, 1mm 허용 범위 밖 돌출은 거절.
- 지원 밖 45도는 ROTATION_UNSUPPORTED, 조용히 직각으로 변경하지 않음.

검사 도구 이름은 예정이며 현재 존재/통과를 주장하지 않는다. 구현 담당자가 실행 가능한 검사와 재현 절차를 함께 제공한다. 순수 로직 검사는 Unity 전체 빌드 없이 실행 가능하게 하고, UI/실행 검사는 실제 Player에서 확인한다.

## 제외 범위

실제 관람객 길찾기, 벽/천장, 일반 다각형, 실물 mesh 충돌.
