## 구현 또는 설계할 내용

1. 시험 씬에서 fixture 또는 지정된 시험 저장을 열고 적용/취소/재실행 복원을 연결한다.
2. 검증→비활성 준비→Commit→활성화 순서를 지킨다.
3. 저장 성공 후 활성화 실패는 별도 상태와 재로딩 안내를 제공한다.
4. 자원 정리와 오류 안내를 검증하고 사용자에게 짧은 조작 시연을 제공한다.
5. 현재 production 씬/개인 Archive는 교체하지 않는다.

## 합격 기준

- 전시대+꽃병 이동·회전·회수·색상 결과가 종료 후 동일하게 복원.
- 편집 전체 취소는 원본 snapshot byte/content 의미 불변.
- 동시 실행/저장 실패/활성화 실패의 화면 안내가 실제 디스크 상태와 일치.
- 실제 마우스 다섯 장면을 확인하고 사용감 수정점을 설정값 또는 계약 문제로 분류.
- 시험판 완료와 실제 박물관 미통합을 명확히 보고.

검사 도구 이름은 예정이며 현재 존재/통과를 주장하지 않는다. 구현 담당자가 실행 가능한 검사와 재현 절차를 함께 제공한다. 순수 로직 검사는 Unity 전체 빌드 없이 실행 가능하게 하고, UI/실행 검사는 실제 Player에서 확인한다.
