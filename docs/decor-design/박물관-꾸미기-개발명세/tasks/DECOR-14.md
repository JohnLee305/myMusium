## 구현 또는 설계

기존 ScreenPoint 기반 선택/배치에서 월드 레이·후보 변환을 분리한다. 공통 의도 봉투와 source/sequence/sessionToken 중복방지·취소·포커스·한 소유자 규칙을 구현한다. Presenter와07공통세션에서 UI위젯 의존을 분리한다. 기존 PC경로는 얇은 임시 연결로 작동하게 유지하며 새 입력 어댑터 연결은15/16에서 한다.

## 합격 기준

동일 후보/의도에서 기존 명령 수·world 의미·Undo 일치, 중복/오래된세션/두소스 경합·추적상실·전환큐폐기 원자성, geometry/저장 회귀 PASS. 기존 PC 표시 smoke 유지. 새검사 실행경로를 run-ci.mjs에 연결. VR 완료 주장 금지.

## 인계와 제외
