# 화면·조작 명세

첫 기준은 1280×800 PC 창이다. 1920×1080과 125/150% 배율에서도 겹치지 않도록 검증한다. 최소 창 1024×720에서는 카드 수를 줄이고 우측 패널을 접는다. 크기·색·카메라 설정은 하나의 EditorPresentationSettings로 모으고 저장 DTO에 넣지 않는다.

## 화면 배치

```text
┌ 방 선택 | 선택 이동 회전 스포이트 | Undo Redo | 취소 적용 ┐
│                                                        │
│                  방 편집 화면             선택 정보    │
│               투명 미리보기 / 윤곽         색·치수·회수 │
│                                                        │
├ 카탈로그 | 보관함 | 소장품 | 공간·마감 ───── 검색 ──────┤
│ 종류 필터    [아이템 카드] [아이템 카드] [아이템 카드]   │
└ 상태: 저장되지 않은 변경 / 잘못 놓은 이유 / 조작 안내 ──┘
```

상단 56px, 하단 목록 기본 220px, 우측 정보판 260px를 기준으로 한다. 카드 104×120px, 썸네일 88×76px를 출발점으로 두고 길어진 한글 이름은 두 줄+상세 툴팁으로 처리한다. 일반 텍스트 16px, 보조 14px를 기본으로 한다. 이 수치는 논리 UI 크기이며 DPI 변환은 UI가 담당한다.

색상은 밝은 중립 패널, 짙은 회색 글자, 녹색 강조, 금색 보조를 기본으로 한다. 오류는 붉은 윤곽+이유 문구, 유효 배치는 녹색 윤곽+‘놓기’ 안내로 구분한다. 프리뷰는 반투명이고 선택물과 구분되게 한다. UI 에셋은 프로젝트 자체 제작분을 사용한다.

PC 꾸미기 화면은 현재 패키지에 있는 UI Toolkit 기반으로 만들고 별도 유료 UI 패키지를 추가하지 않는다. 런타임 입력·포커스 문제를 시제품에서 확인한다. 기존 OnGUI 관람 화면을 전부 바꾸는 작업은 포함하지 않는다. 다른 UI 기술로 교체할 이유가 나오면 구현 카드에 근거를 남기고 설계 검토한다.

## 입력 표

| 입력 | 동작 | 충돌 방지 |
|---|---|---|
| 왼쪽 클릭 | 물건 선택 / 프리뷰 놓기 | UI 위 클릭은 방에 전달하지 않음 |
| 가운데 버튼 드래그 | 카메라 평행 이동 | 물건 이동과 별도 |
| 오른쪽 버튼 드래그 | 방 중심 또는 선택물 중심으로 카메라 회전 | 클릭만으로 취소하지 않음 |
| 휠 | 커서 근처로 확대·축소 | UI 목록 위에서는 목록 스크롤 |
| WASD / 방향키 | 카메라 이동 | 검색 입력 중 무시 |
| Q / E | 선택물·프리뷰를 한 단계 회전 | 활성 물건이 없으면 동작 없음 |
| M | 선택물 이동 미리보기 | 직접 저장하지 않음 |
| I | 스포이트 도구 | 클릭한 정의·색상 선택 |
| F | 선택물 또는 현재 방에 카메라 맞추기 | 관람 모드의 F와 분리 |
| G | 배치 눈금 표시 전환 | snap 활성 여부는 별도 |
| Alt 누름 | 위치 snap 일시 해제 | 표면·충돌 규칙은 유지 |
| Shift+놓기 | 같은 정의·색상 연속 배치 | 매번 새 ID, 취소 프리뷰는 수량에 포함 안 됨 |
| Delete | 선택 루트를 보관함으로 회수 | 부모 포함 회수 여부는 아래 규칙 |
| Ctrl+Z / Ctrl+Y | 편집 Undo/Redo | 텍스트 필드에서는 텍스트 편집이 우선 |
| Ctrl+S | 적용과 같은 명령 | ‘편집 중 조용한 확정 저장’ 경로를 만들지 않음 |
| Esc | 프리뷰 취소 → 선택 해제 → 모드 종료 확인 | 한 번 눌러 모든 변경 폐기하지 않음 |

키 변경은 후속 설정으로 확장할 수 있게 InputAction 이름을 사용한다. 위 키가 현재 입력 자산과 충돌하면 모드별 action map을 분리한다. PC 빌드와 에디터 입력을 따로 검사한다.

## 선택과 표면 부착

레이가 꽃병에 닿으면 꽃병을 선택한다. 전시대를 선택하려면 전시대 부분을 클릭하거나 정보판의 ‘받침대 선택’을 누른다. 선택물 자손 전체는 약한 윤곽, 직접 선택물은 강한 윤곽으로 구분한다.

새 소품을 고르면 지원하는 상판만 강조한다. 허용되지 않은 바닥 위에서는 프리뷰를 빨갛게 표시하고 ‘전시대나 선반 위에 놓으세요’라고 안내한다. 여러 상판이 겹치면 카메라에서 가장 가까운 유효 면을 우선하고, Tab으로 후보를 순환한다. 첫 시험판은 상판 하나만 지원해도 되지만 보이지 않는 면에 자동으로 붙이지 않는다.

프리뷰 중 우측 정보판은 선택 색상·치수·설치 면을 보여준다. 원본 모델의 실제 크기는 유지한다. Alt 자유 위치는 1mm 저장 정밀도로 정규화하며, 표면 높이에서 벗어나는 Y 이동을 허용하지 않는다.

## 회수·취소·확인창

- 꽃병 회수: 꽃병만 storage로 옮긴다.
- 전시대 회수: 모든 소품을 붙인 상태로 보관한다. 완료 토스트에 ‘전시대와 소품 1개를 보관했습니다 · 되돌리기’를 표시한다.
- 프리뷰 취소: 기존 물건이면 이동 전 위치로, 새 물건이면 프리뷰만 제거한다.
- 전체 취소: 변경이 있으면 ‘변경 버리기 / 계속 꾸미기’ 확인창. 변경이 없으면 바로 관람으로 돌아간다.
- 적용: 오류가 있으면 목록과 위치 이동 버튼을 표시한다. 경고는 구분해서 보여주며 통로 단절 오류를 무시하는 버튼은 제공하지 않는다.
- 정상 배치·회수·색상 변경에는 매번 확인창을 띄우지 않는다.

벽 보기는 전체/단면/숨김 세 상태를 제공한다. 숨김은 편집용 표시만 바꾸고 충돌·저장 상태는 바꾸지 않는다. 현재 방 천장은 기본 숨김이다. 천장등 단계에서는 천장 편집 도구로 진입할 때 부착 면을 표시한다.

## 체감 검토 장면

1. 목록에서 전시대 선택→놓기→다른 색상 적용.
2. 꽃병 선택→상판에 놓기→5cm 옮기기→한 번 Undo.
3. 전시대를 옮기고 회전→꽃병이 따라가는지 확인.
4. 전시대 회수→보관함에서 다시 설치→같은 색과 꽃병 유지.
5. 출입구 앞 이동 시 거절→올바른 위치로 수정→적용→관람.

설계 담당자는 이 다섯 장면을 먼저 검토한다. 패널 간격·카메라 감도는 여기서 조정하고 ID·저장 계약을 바꾸어 해결하지 않는다.
