# DECOR-06 배치 조작 연결 인계

PR54 통합판에서 별도 브랜치와 Issue55로 시작했다. 저장 DTO/schema와 기존 명령 의미는 변경하지 않는다. 실제 관람객·영구 저장·자유 yaw·벽/천장은 범위 밖이다. 통과한 검사와 미검증 범위는 작업 handoff가 정본이다.

## 조작 흐름

- 카탈로그 카드 → 투명 프리뷰 → 방 바닥/보이는 상판 가리키기 → 클릭 확정.
- 물건 선택 후 M 또는 이동 버튼 → 프리뷰 → 클릭 확정. Esc는 현재 프리뷰만 취소한다. 프리뷰가 없으면 선택 해제한다.
- Q/E 또는 회전 버튼은 90도 회전이다. Alt는 위치 snap을 잠시 끄며 1mm 정밀도와 지지·충돌은 유지한다.
- Shift+놓기는 새 물건 연속 배치다. 매 성공마다 새 ID를 사용한다. 보관 물건을 연속 복제하지 않는다.
- 색상 칩은 새 물건 프리뷰 또는 선택된 물건에 적용한다. 기존 물건 이동·재설치 프리뷰 중에는 확정/취소 후 색상을 바꾸라고 안내한다. 이동과 색상 변경을 몰래 다른 명령으로 쪼개지 않는다.
- Delete/보관 버튼은 선택물과 붙은 소품을 보관한다. 보관함은 실제 개체·최근 회수 순을 사용한다. 복원 시 기존 ID·색상·소품 참조를 유지한다.
- Ctrl+Z/Y와 버튼으로 Undo/Redo한다. 검색 입력 중에는 편집 단축키와 카메라 입력을 차단한다.
- I 스포이트는 다음에 클릭한 물건의 정의와 색상을 새 프리뷰로 선택한다. 기존 개체나 자손을 복제하지 않는다.

이번 시험 화면의 변경은 메모리 안에만 있다. 창을 종료하고 다시 실행하면 가상 fixture로 시작한다. 영구 적용·관람 복귀·전체 변경 폐기는 DECOR-07 이후 연결한다.

## 구성과 경계

`Domain/DecorInteraction.cs`는 Unity 없이 실행되는 입력 조정기다. DecorPlacementValidator.BeginEdit로 편집 세션을 만들고 원본과 초안/프리뷰를 분리한다. 프리뷰는 스냅샷 복사본을 검사하며 ApplyCommand를 호출하지 않는다. 유효한 확정 클릭만 명령 하나를 제출한다. 거절/취소는 소유 수량·Undo/Redo를 변경하지 않는다. 외부로 반환한 프리뷰와 스냅샷은 복사본이다.

`UI/DecorEditorController.cs`는 포인터를 설치 위치로 변환한다. 가구는 바닥 평면, 소품은 실제 레이가 먼저 맞힌 보이는 상판을 사용한다. 상판 높이·윗면 법선·부모 로컬 좌표를 확인하고 공통 geometry 검사를 거친다. 임의의 숨긴 평면으로 자동 부착하지 않는다. 첫 시험판은 정의의 첫 상판만 사용한다.

`UI/DecorPlacementPreview.cs`는 프리뷰와 자손 도형을 표시하고 녹색/빨강 두 재질을 재사용한다. 취소·확정·비활성화 때 임시 도형을 해제한다. 기존 물건은 확정 전 원래 위치에 남아 있고 프리뷰는 투명 도형으로 구분한다. 위치 오류는 상태줄의 짧은 한국어 이유와 붉은 프리뷰로 표현한다.

`DecorPanel.RefreshWorld`는 성공한 명령의 스냅샷만 반영한다. 아이템 렌더 도형을 갱신하고 색상별 재질을 재사용한다. 방·벽·그리드는 명령마다 재생성하지 않는다. UI 정보 조회의 선택 이벤트와 명령 후 화면 동기화를 구분해 연속 프리뷰가 선택 이벤트 때문에 취소되지 않게 한다.

## 재현


순수 검사는 실제 production C#을 컴파일한다. 실제 Player 검사는 Input System 이벤트를 사용해 UI 클릭과 방 클릭, 키 조작을 수행한다. 합성 장치의 입력과 사람의 실제 마우스 조작 검증을 구분한다. 화면 캡처와 로그는 logs에 남기며 개인 Archive를 사용하지 않는다.

## 후속 검토

DECOR-07에서 실제 사람이 체감 장면1~4를 확인하고 영구 저장/적용·취소와 마지막 문 앞 수정→적용→관람 장면을 연결한다. 관람객 전체 길찾기는 문 예약공간 충돌과 별개의 DECOR-08 Gate다. PC 검사만으로 Quest 조작 완료라고 기록하지 않는다.

최종 검증: 입력독립production C#31 + 실제표시된Windows Player92 PASS. 기존 Node15/계약204/명령132/저장62/충돌127 포함 전체회귀 PASS. 실제Player의 합성마우스/키보드로 조작 장면1~4를 자동수행했으며, 사람 실제마우스 체감검토는 사용자 확인 대기다. 로그와 경계는 handoff 참조.
