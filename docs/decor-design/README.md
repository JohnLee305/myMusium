방은 독립된 이공간이며, 웹은 에셋 등록, 박물관 내부는 배치·꾸미기를 맡는 방향이다. 심즈식 카탈로그·보관함·스포이트·색상·연속 배치·Undo를 기본 경험으로 정했다.

01~07은 가상 방의 전시대·꽃병 시험판, 08~12는 실제 박물관 연결 및 후속 확장의 설계/통합 Gate다. 경제·공간 확장은 후속이며 기존 관람객의 신규 확장은 현재 우선순위가 아니다.

개인 소장품과 현재 실행판은 변경하지 않았다. JSON 형식 검증과 실제 게임 기능 검증을 구분한다. 초기 설계초안은 논의 이력이며 충돌하면 구현 위임 명세를 따른다.
