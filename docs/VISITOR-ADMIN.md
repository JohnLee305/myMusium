# 관람객 웹 관리 안내

## 관람객 관리·저장 (ADMIN-005 / 2026-10-15)

1. 바탕화면 **VR 박물관 관리**를 열고, 꺼져 있으면 **서버 켜기**를 누릅니다.
2. **관리페이지 열기** → 위쪽 **관람객 관리**에서 받기 여부·목표0~6명·이동0.5~1.5배를 정합니다.
3. 캐릭터 사용 여부와 등장 비중0~100을 정하고 **관람객 설정 저장**을 누릅니다. 현재101종(기존1+남녀100조합)입니다. 검색/12개씩 페이지/모두 사용·끄기를 제공하며, 다른 페이지의 수정값도 함께 저장합니다. 비중은 현재 방에 없는 사용 가능 외형을 우선 고른 뒤 상대 선택 확률로 적용합니다.
4. 바탕화면 **PC 관람**은 같은 실험 자료를 읽습니다. 저장은 실행 중 약1초 안에 반영되고 앱/서버를 다시 열어도 유지됩니다. 앱 안 인원 버튼은 임시이며, 웹에서 다시 저장하면 저장값이 우선합니다.

서버는 웹에서 저장할 때 필요하며, 관람만 할 때는 꺼도 됩니다. 전시품·배치·테마 변경은 기존처럼 앱 재실행이 필요합니다. 외형을 끄면 해당 손님을 정리하고, 비중 변경은 다음 입장부터 적용합니다. 모든 외형을 끄거나 비중을0으로 하면 손님이 생성되지 않습니다.

설정은 해당 archive의 visitors.json에 별도로 저장합니다. 전시 목록 manifest.json을 바꾸지 않으며 이전 설정은 .admin-backups에 보관합니다. 잘못된 설정 파일은 앱에서 마지막 정상 설정을 유지하고 웹에서는 오류를 안내합니다. 손상 파일의 자동 복구 UI는 제공하지 않습니다.

새 외형은 Unity 프로필/카탈로그 등록 후 실험 앱을 빌드합니다. 성공한 BuildDesktop이 실제 카탈로그를 apps/curator-admin/visitor-catalog.json에 내보내므로 웹 목록에도 나타납니다. Unity에서 비활성/유효하지 않은 외형은 웹에서 활성화할 수 없습니다. 관리페이지에서 캐릭터 파일을 직접 업로드하는 기능은 아닙니다.

최신 관리:4181 / 실험 archive. **VR 박물관 관리 (기존 버전)**:4177 / 기존 archive. tools/setup-admin-shortcuts.ps1로 바로가기를 다시 생성할 수 있습니다. 두 자료는 자동 병합하지 않습니다.
