# ADR-0006 · 승인된 전시품 감상 반응과 데이터 경계

결정일: 2026-10-16. 범위: REACT-001~008 PC 첫 버전 및 ARCH-002/003 관련 최소 호환 계약. 전체 Archive v2/자산 변환/게임 세이브 설계 완료를 의미하지 않는다.

## 결정

- `artifact.json`/`manifest.json` v1은 변경하지 않는다. 전시품 폴더의 선택적 `reactions.json` 1.0에 원문 스냅샷·SHA-256·감상 근거·반응 후보·승인 상태를 저장한다.
- 원문 지문은 UTF-16 코드 유닛 길이를 10진수로 붙인 `title.length + ':' + title + description.length + ':' + description`의 UTF-8 바이트 SHA-256이다. 줄바꿈 정규화 없이 읽은 문자열을 사용하며 모델/배율/방배치는 입력이 아니다. 필드 경계가 모호한 단순 구분자 연결을 사용하지 않는다.
- 반응 파일은 원문에 종속된 편집 콘텐츠이다. 외형/방 배치/타이쿤 진행 저장과 분리한다. 파일 없음은 정상이다. 캐시 삭제·게임 초기화가 소장품/원문/검토 결과를 지워서는 안 된다.
- 원문 지문이 다르면 문구의 저장된 승인 상태와 무관하게 런타임에서 제외한다. Admin은 stale를 표시하고 새 원문 후보를 검토하게 한다. 과거 내용은 백업에 보존한다.
- 같은 원문으로 재생성하면 기존 문구/승인을 유지하고 없는 템플릿 ID만 추가한다. 원문 변경 시 새 초안으로 만들며 교체 전 이전 파일을 백업한다.
- 스키마: 파일 64KiB, 근거 16개, 반응 48개, 문구 72 UTF-16 코드 유닛. 중복 ID/없는 근거 참조/원문에 없는 인용/HTML·제어문자/잘못된 상태·성향 거부. JSON Schema 외 의미 검사는 Node와 Unity의 공통 fixture로 확인한다. Unity는 중복 JSON 키/잘못된 토큰도 거부한다.
- 수정은 세션 토큰·동일 Host/Origin 및 원문 지문/반응 revision을 확인한다. 공용 저장 잠금, 백업, 같은 디렉터리 임시파일→rename 게시를 사용한다. 실패 시 이전 정상본 유지. 원본 JSON·모델·manifest를 반응 API에서 수정하지 않는다.
- 현행 휴지통은 manifest 배정만 제거하므로 사이드카도 함께 보존된다. 복원 후 원문이 같으면 기존 승인문을 다시 사용할 수 있다. 영구 삭제/Archive 이동은 별도 생애주기 작업이다.
- Node에서 수동 입력 및 원문 인용 템플릿만 생성한다. 네트워크/AI/키 필요 없음. 희귀성·역사·제작자를 추론하지 않는다. 관리자가 사실·표현을 확인한 승인문만 표시한다.
- NPC의 general/detail/story/collector 관심 성향을 외형과 별개로 방문 시 무작위 부여한다. 현재 장르 선호 가중치/장기 성향 저장은 구현하지 않는다.
- Unity의 실제 Walking→Viewing 진입에서 대상 Artifact ID·성향으로 승인 후보를 선택한다. 동일 손님 최근 8개/전시품 최근 2개(30초)를 억제한다. 후보를 모두 최근 사용했으면 그 감상은 조용히 넘긴다. rare 후보는 선택 기회 약10%, ordinary 없을 때도 남발하지 않는다.
- 누락/손상/stale/해당 성향 승인 후보 없음은 기존 일반 문구로 폴백한다. 유효한 문서에서 `enabled=false`면 해당 전시품 말풍선을 숨긴다. 전역 표시 끄기는 현재 앱 세션에 적용한다.
- 7m 이내 앞쪽의 가까운 감상자 최대2명, 감상 시간4.5초, 18글자 단위 줄바꿈·배경판·깊이 판정으로 표시한다. PC 먼저 검증하며 Quest 가독성·거리감은 별도 미검증이다.
- 방 전환/꺼짐/종료 시 관람객·말풍선·소유 배경 재질을 정리하고 방별 최근 선택 이력을 초기화한다. 기존 외형 모델/애니메이션/선택·이동 경로는 유지한다.

## 확장 경계

반응 콘텐츠는 `reaction-service.mjs`/`reactions.mjs`, 런타임 로딩·선택은 `ReactionCatalog`, UI는 `reaction-editor.js`로 분리한다. MuseumVisitors/Guest에 생성·편집·LLM 호출을 넣지 않는다. 새 HTTP DataSource/PC·MOBILE 변환/원격 캐시·경제 세이브는 이번 계약의 필수 조건이 아니다.

## 검증

`node tools/test-reactions.mjs` → `tools/run-unity.ps1 -Task Build` → `tools/test-reactions-player.ps1`. 공통 유효·무효 fixture, API 인증/충돌/복원/원문 변경, 세 전시품×네 성향, 반복·손상·미승인·꺼짐·실제 감상 진입·방 전환·최대6명 검사. 실제 결과는 STATUS/WORKLOG에 기록한다.
