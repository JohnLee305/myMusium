# ADR-0007 · 반응 96개 상한과 기준 v2

결정일: 2026-10-16. 범위: REACT-015. ADR-0006(48개 상한)의 후속이며 1,000개 확장(REACT-012/013)의 완료를 의미하지 않는다.

## 결정

- `reactions.json` 1.0의 후보 상한을 48개에서 96개로 확장한다. 파일 64KiB·근거 16개·문구 72 UTF-16 코드 유닛·HTML/제어문자 금지는 유지한다. 96개 실측 약17KiB이므로 바이트 상한 변경은 불필요하다.
- 상한 변경은 Node(`reactions.mjs` 검증·생성 채움)·Unity(`ReactionCatalog` 파싱·strict JSON 배열)·관리 에디터(추가 제한 문구)·테스트(경계 96/97)를 동시에 적용한다. 숫자 하나만 바꾸지 않는다.
- `persona`는 `general/detail/story/collector` 4종을 생성·표시 기본값으로 유지하되, 검증에서는 ID 형식의 새 값을 허용한다. 새 성향값은 저장·검토가 가능하고, 실제 표시는 guest 성향 부여(관심 프로필)가 따라야 한다. 에디터는 미등록 성향명을 그대로 표시하고 전체 성향 필터에 포함한다.
- 기존 승인문은 96개 확장으로 무효화되거나 교체되지 않는다. 새 48개는 draft로 저장하고 사용자 승인 전 런타임에 노출하지 않는다.

## 기준 v2(콘텐츠)

- 설명 사실 허용 + 직접 본 외형 + 사람다운 감상(기억·연상·질문·공감)을 구분해 작성한다. 미확인 재질 성분·제품명·제작자/연도/국가·성능·사용 이력 단정은 계속 금지한다.
- tier(짧은 감탄/보통 감상/드문 코멘트)는 유지하고, 감정 8종(호기심/놀람/따뜻함/차분함/유쾌함/아련함/감탄/공감)을 문구에 직교로 배분한다.
- 같은 의미의 조사/어미/동의어 교체는 독립 반응으로 세지 않는다.
