# 0004: 방당30개와 전시실별 로딩

날짜: 2026-09-28

사용자 요청에 따라 전시실당 최대30개, 초과시 자동방추가, 방이동시 로딩, HTML 관리기능을 구현한다. 기존 ADR0003의6개/초과생략은 이 결정으로 대체한다.

manifest.artifacts를 전체 원본목록으로 유지하고 선택적 rooms로 방의 id/title/artifacts를 저장한다. 기존 자료에는 rooms가 없어도30개씩 자동분할한다. 모든 전시품은 정확히 한 방에 배정하며 빈방을 허용한다. 파일을 복사하지 않고 배정만 바꾸므로 이동에 모델저장공간이 늘지 않는다.

관람은 같은 씬의 공간을 방 크기에 맞춰 구성하고 전시품 루트를 교체한다. 데스크톱 이동 잠금과 진행 안내 후 새 방을 준비하고 이전 루트/importer/font를 정리한다. 안정 상태에서 현재방만 남지만 전환 중 두 방 자원이 공존할 수 있다. 실제 방 사이에 긴 복도나 연속 월드 스트리밍을 만드는 방식은 아니다.

HTML은 새방생성/등록대상방선택/방별필터/기존전시품방이동을 지원한다. 자동배정은 첫여유방→없으면새방. 지정방이 꽉 차면 명시적 오류. 모든 저장에 manifest 백업 유지. 변경사항은 Viewer 재실행 후 반영된다.

상한10000개/방1000개/manifest4MiB는 로컬 안전상한이고 성능보증이 아니다. 30개 샘플과31개 경계, 빈방, 부분실패를 검증한다. Quest 실기기/대형 실제모델/장시간 메모리성능은 후속이다.
