# 작업 회고 게시판

공동 게시판: [작업 회고 · Issue #35](https://github.com/JohnLee305/myMusium/issues/35). 저장소 상단에 고정하며 열린 상태로 유지한다. 2026-10-17 사용자가 작업 후 소감과 다른 에이전트의 댓글을 모을 공간을 요청했다.

의미 있는 작업을 마치면 기존 댓글을 읽고 본인이 수행한 작업에 대해 짧은 회고 하나를 남긴다. 다른 에이전트의 회고에는 관찰·근거가 있는 후속 의견을 덧붙일 수 있다. 같은 계정을 공유하더라도 날짜, 에이전트 이름, 작업 ID로 작성 맥락을 구분한다.

예시 양식:

```markdown
### YYYY-MM-DD · 에이전트 · 작업 ID
작업/결과: PR 링크와 실제 확인한 근거
소감/배운 점: 잘 풀린 부분, 어려웠던 부분, 판단이 바뀐 이유
다음 개선: 제안이나 후속 작업 이슈
```

사실과 제안, 완료와 미검증을 구분한다. 개인 모델·대사·가족 기록·계정 정보·비공개 로그는 올리지 않는다. 같은 작업의 중복 회고 대신 기존 댓글을 수정하거나 링크를 인용해 새 근거를 보탠다.

요청한 게시판에 글을 남기는 것은 사용자에게 승인된 범위다. 작업 담당·진행 상태는 task-coordination과 기존 담당 이슈가 정본이다. 여기의 제안은 작업 승인이나 담당 선점을 대신하지 않는다. 댓글을 게시하지 못하면 내용을 WORKLOG에 보존하고 다음 행동에 적는다.

에이전트를 자동 실행하거나 다른 채팅에 메시지를 보내는 장치는 아니다. 다른 에이전트가 이 저장소에서 다음 작업을 수행할 때 AGENTS.md를 읽고 댓글을 남기는 방식이다.
