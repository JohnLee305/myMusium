# 전시품 감상 반응 · PC 첫 버전

관련: REACT-001~008, [ADR-0006](decisions/0006-approved-reactions.md). 기존 전시품 v1과 호환되는 선택적 기능이다.

## 사용

1. 최신 반응 기능 관리페이지에서 **감상 반응 만들기**를 누른다.
2. 전시품을 고르고 **설명에서 반응 후보 만들기**를 누른다. 일반·디테일·이야기·수집가 네 관점의 후보가 생성된다. 외부 AI 전송은 없다.
3. 원문과 인용 근거를 읽고 문구를 직접 수정하거나 추가한다. 사실이 맞는 후보의 상태를 **승인**으로 바꾸고 **검토·승인 결과 저장**을 누른다. 수정한 문구는 자동으로 검토 중이 된다.
4. 최신 PC 관람 앱을 다시 연다. NPC가 전시품 앞에서 실제 감상할 때 관심 성향에 맞는 승인 반응을 표시한다. 한 성향만 승인하면 다른 성향은 기존 일반 문구를 쓴다.

원문이 바뀌면 이전 승인문은 검토 필요로 표시되고 사용되지 않는다. 새 원문으로 후보를 만든 뒤 재승인한다. 기존 승인 내용은 **이전 저장 복원**에서 최근20개까지 선택할 수 있으며 디스크 백업 자체를 자동 삭제하지 않는다. 설명이 다른 과거 저장을 복원해도 승인 반응이 바로 나타나지 않는다.

**표시 제어:** 전시품별 체크박스는 저장된다. PC 관람객 패널의 감상 반응 표시는 현재 세션 전체를 켜고 끈다. 가까운7m 이내 앞쪽 감상자 최대2명, 감상4.5초 동안 표시한다. 같은 손님/작품의 최근 문구는 억제하므로 매번 말풍선이 생기지는 않는다. 반응 자료가 없거나 손상된 경우 기존 일반 문구로 관람을 유지한다.

## 저장·운영

- `artifacts/{id}/reactions.json`에 원문 스냅샷/지문·근거·후보/승인 상태를 저장한다. `artifact.json`/모델/배치/관람객 인원 설정은 바꾸지 않는다.
- 반응 파일64KiB, 감상 근거16개, 후보48개, 문구72 UTF-16 코드 유닛. HTML과 제어문자는 허용하지 않는다.
- 다른 화면에서 원문/반응을 수정하면409 오류로 덮어쓰기를 막는다. 입력을 확인한 뒤 다시 불러온다.
- 현재는 원문에서 한 감상 포인트를 그대로 인용하는 보수적인 템플릿 MVP이다. 심층 의미 분석·자유로운 AI 생성·음성/대화·장르 선호/만족도는 후속이다.
- 개인/가족 이야기와 반응 초안·승인문도 개인정보일 수 있다. 실제 Archive와 `.admin-backups`를 공개 Git에 자동 추가하지 않는다. 이번 검증은 별도 가상자료로 진행한다.

## 이번 개발 위치

소스·빌드: `C:\Dev\vr-museum-sync-20261016`. 기존 `C:\Dev\vr-museum-tycoon`의 미커밋 전시 자료는 보존했다. 기존 바탕화면 바로가기가 새 실행본을 가리킨다고 가정하지 않는다. 관리 서버를 실행할 때 같은 Archive 경로를 명시하고 기준4177/기존 실험4181과 다른 포트를 사용한다.
