# REACT-010 · 모델별 반응량과 모델당1,000개 확장 방향

결정/요청일: 2026-10-16. 사용자 요구는 **모델마다 최소30개를 넘는 서로 다른 생각**, 장기 목표는 모델당 약1,000개다.

## 이번 구현

- 정상적인 텍스트 설명의 새 모델 등록 시 staging 안에 **40개 초안(4성향×10개)**을 준비한다. 모델/metadata/반응을 함께 게시하고 중복 등록/게시 실패로 기존 자료를 덮어쓰지 않는다.
- 자동40개는 원문 인용과 감상 질문을 조합하는 **설명 기반 템플릿**이다. 업로드한 GLB를 자동으로 시각 해석하는 기능은 아니다.
- 기존8개 후보는 다시 생성하면40개로 보충한다. 같은 원문의 기존 수정·승인·거절 상태는 유지한다. 이미48개인 수동 맞춤 문구도 교체하지 않는다.
- 반응 파일 생성이 지원하지 않는 원문 형식이면 기존 v1 전시품 등록은 유지하고 반응 검토가 필요하다고 안내한다. 디스크 게시 오류는 기존 등록의 원자적 실패 경로를 따른다.
- 수동 외형 맞춤은 사용자가 명시한 모델을 직접 관찰하여 작성한다. 이번 사용자 지정 모델은48개를 로컬 개인 Archive에 draft로 저장했다. 원래 모델·설명은 변경하지 않았고 실제 문구/모델/관찰 화면은 공개 Git에 넣지 않는다.
- 관리 UI는12개씩 페이지, 문구 검색, 성향/검토상태 필터, 승인·초안·거절 개수, 현재 페이지 승인/거절을 지원한다. 페이지/필터를 바꿔도 입력 draft를 유지하고 저장 버튼으로 전체 변경을 적용한다.
- **현재 계약은 계속 최대48개·64KiB·문구72 UTF-16 코드 유닛이다.** UI에 페이지가 생겼다고1,000개 저장이 가능한 것은 아니다.

## 외형 맞춤 작성 원칙

모델을 여러 각도에서 보고 색/윤곽/표면/구성/입체적 대비를 기록한다. 확인되지 않은 재질의 실제 성분, 제품명, 제작자/연도/국가, 성능·사용 이력은 단정하지 않는다. 등록 설명의 사실과 관찰에서 얻은 시각적 인상, 가상의 질문을 구분한다.

현재는 수동 작성 후보가 `evidencePointIds:[]`일 수 있다. 이것을 원문 인용 근거가 있는 문장이라고 표시하지 않는다. 해당 전시품 폴더의 로컬 `reaction-observations.md`에 모델 SHA-256/설명 지문/관찰 내용과 미확인 사항을 함께 보관하고 관리자가 모델과 대조하여 승인한다. 이 메모는 런타임 스키마 필드가 아니며, **모델 바이트 변경의 자동 무효화도 현재 구현되어 있지 않다**. 모델 교체 시 재검토가 필요하다.
